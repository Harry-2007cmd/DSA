## 📁 Repository Structure

Each problem lives in its own folder, named after the problem's LeetCode slug and prefixed with its problem number:

```
<problem-number>-<problem-slug>/
├── README.md              # Problem statement, examples, and constraints
└── <problem-slug>.java    # Java solution
```

Example:

```
1-two-sum/
├── README.md
└── two-sum.java
```

## 🚀 Getting Started

### Prerequisites

- [Java Development Kit (JDK) 8+](https://www.oracle.com/java/technologies/downloads/)

### Running a Solution

Each solution is written as a standalone `Solution` class matching LeetCode's submission format. To run one locally, wrap it with a small driver:

```bash
# Example: running the Two Sum solution
cd 1-two-sum
```

```java
public class Main {
    public static void main(String[] args) {
        Solution sol = new Solution();
        int[] result = sol.twoSum(new int[]{2, 7, 11, 15}, 9);
        System.out.println(java.util.Arrays.toString(result));
    }
}
```

```bash
javac Solution.java Main.java
java Main
```
